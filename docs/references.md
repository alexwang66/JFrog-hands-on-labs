## 課前驗證原則

1. 先查看租戶與 CLI 版本。
2. 對會更動狀態的命令先執行對應 `--help`。
3. 固定 Workshop 使用的資產與版本。
4. 以學員最小權限帳號重走完整流程。
5. 對 Beta 或未開通能力準備替代證據，不在現場臨時放寬政策。
