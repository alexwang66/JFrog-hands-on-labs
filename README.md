# JFrog Copilot Workshop

在 GitHub Codespaces 中使用 Copilot 練習 JFrog Skills 與 MCP。

## 開始使用

1. 在 GitHub 選擇 **Code → Codespaces → Create codespace on main**。
2. 開啟 Copilot Chat。
3. 開啟 [Module 1](modules/01/README.md)，先在 Codespace Terminal 安裝並設定 JFrog CLI，再將提示詞貼到 Copilot Chat。

Codespace 使用既有的 `JFROG_ACCESS_TOKEN` Secret；不要將憑證貼到聊天或檔案。

## 設定

| 項目 | 值 |
|---|---|
| JFrog Platform | `https://alexwangtrial.jfrog.io` |
| Server ID | `workshop` |
| Project | `workshop` |
| 核准的 npm Virtual Repository | `workshop-npm` |

JFrog Skills 與 MCP 的實際安裝及驗證由 Module 1 提示詞引導；若必要 Repository 或 Catalog 資產不可用，應安全停止並由講師處理。
